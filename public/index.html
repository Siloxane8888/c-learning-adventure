🛠️ Visual Studio C 语言开发环境搭建

从零开始，保姆级教程 — 每一步都有截图说明

📥 第一步：下载 Visual Studio

打开浏览器，访问 visualstudio.microsoft.com/zh-hans/downloads/

选择 Visual Studio Community 2022（免费版），点击「免费下载」。

💡 Community 版完全免费，包含我们需要的所有 C/C++ 开发工具。

⚙️ 第二步：安装 — 选择工作负载

运行下载的安装程序，在「工作负载」标签页中，务必勾选：

✅ 使用 C++ 的桌面开发（Desktop development with C++）

右侧确认以下组件已勾选：

  • MSVC v143 - VS 2022 C++ x64/x86 生成工具
  • Windows 11 SDK（或 Windows 10 SDK）
  • C++ 核心桌面功能

点击右下角「安装」，等待 15-30 分钟。

💡 安装包约 3-5 GB，建议连接电源和稳定网络。

🚀 第三步：创建第一个 C 项目

1启动 VS 2022，点击「创建新项目」
2搜索框输入 C++，选择「空项目」（Empty Project）
3项目名称填入 hello_c，选择保存位置，点击「创建」
4在右侧「解决方案资源管理器」中右键「源文件」→「添加」→「新建项」
5文件名改为 main.c（注意扩展名是 .c 不是 .cpp！），点击「添加」

✍️ 第四步：编写并运行代码

在打开的 main.c 中输入以下代码：

#include <stdio.h>
int main() {
    printf("Hello, C World!\\n");
    return 0;
}

按 Ctrl + F5（或菜单「调试」→「开始执行(不调试)」）编译并运行。

看到黑色控制台窗口输出 Hello, C World! 即表示成功！🎉

🔧 常见问题与技巧

问题解决方法
找不到 C++ 项目模板重新运行 VS Installer，确认勾选了「使用 C++ 的桌面开发」
控制台窗口一闪而过用 Ctrl+F5 而非 F5，或在 return 0; 前加 getchar();
编译错误 C4996VS 建议用 scanf_s 替代 scanf，在本平台中直接使用标准 scanf 即可
中文乱码文件 → 高级保存选项 → 编码选「Unicode (UTF-8 带签名) - 代码页 65001」
代码提示不工作确认文件扩展名为 .c（C 语言），而非 .cpp（C++）

💡 VS 快捷键速查

快捷键功能
Ctrl + F5编译 + 运行（不调试）
F5调试模式运行
Ctrl + K, Ctrl + D自动格式化代码（对齐缩进）
Ctrl + K, Ctrl + C注释选中行
Ctrl + K, Ctrl + U取消注释
Ctrl + Shift + B仅编译（不运行）
Ctrl + -跳回上一个位置
